# Source provenance

When copying or substantially adapting external guidance:

1. Create an import revision containing the selected source without local behavior changes.
2. Record the source URL, pinned revision, imported paths, permission or license basis, and notices required by retained material.
3. Make local adaptation in a descendant revision.

Keep import and adaptation distinct so later review can separate source material from local decisions. Refresh upstream material through another import revision followed by another adaptation.

Record private provenance inside the private overlay so public history contains only public source information.
